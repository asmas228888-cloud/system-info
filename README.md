Python script for collecting system information
# Лабораторная работа №1

## Описание лабораторной работы:

Цель лабораторной работы — разработать кроссплатформенный Python-скрипт, который определяет операционную систему, на которой он запущен, собирает основные параметры текущей системы и сохраняет полученную информацию в файл формата JSON.

Программа должна работать в операционных системах **Windows, Linux и macOS**. Разрешается использовать стандартные модули Python, а также внешние модули при наличии обоснования их использования.

### Задачи лабораторной работы

В рамках работы необходимо:

1. Разработать скрипт, определяющий операционную систему.
2. Реализовать сбор основных параметров текущей ОС и компьютера.
3. Сохранить полученную информацию в файл формата JSON.
4. Обеспечить возможность запуска программы в Windows, Linux и macOS.

## Описание работы программы

Программа последовательно выполняет несколько этапов.
Сначала с помощью модуля `platform` определяется операционная система. Функция `platform.system()` возвращает название системы. Для Windows возвращается `Windows`, для Linux — `Linux`, а для macOS — `Darwin`. Значение `Darwin` в программе преобразуется в более понятное название `macOS`.
После определения ОС программа собирает основные сведения о системе: версию и релиз операционной системы, архитектуру компьютера и информацию о процессоре.
Затем собирается информация о компьютере и текущем окружении Python. Программа получает имя компьютера, имя пользователя, версию Python и текущую рабочую директорию.
После этого определяется количество доступных логических процессоров.
Следующим этапом программа получает информацию о дисковом пространстве текущей рабочей директории: общий объём, занятый объём и свободное место.
Также программа определяет имя компьютера в сети и его IP-адрес. Для получения IP-адреса используется обработка исключения `try/except`, поскольку определить IP-адрес таким способом удаётся не во всех конфигурациях сети.
Все полученные данные объединяются в один словарь `data`.
В конце программа создаёт файл `system_info.json` и записывает в него собранную информацию с помощью модуля `json`. Полученный JSON форматируется с отступами, поэтому его удобно читать человеку.
После завершения работы программа выводит сообщение об успешном сборе информации и полный путь к созданному JSON-файлу.

## Собираемые параметры

Программа собирает следующие параметры:

| Параметр            | Описание                          |
| ------------------- | --------------------------------- |
| `REQUEST TIME`      | Дата и время сбора информации     |
| `OS name`           | Название операционной системы     |
| `OS version`        | Версия операционной системы       |
| `OS release`        | Релиз операционной системы        |
| `OS architecture`   | Архитектура системы               |
| `CPU`               | Информация о процессоре           |
| `computer name`     | Имя компьютера                    |
| `user name`         | Имя текущего пользователя         |
| `python version`    | Версия Python                     |
| `current directory` | Текущая рабочая директория        |
| `threads`           | Количество логических процессоров |
| `disk total bytes`  | Общий объём диска                 |
| `disk used bytes`   | Использованный объём диска        |
| `disk free bytes`   | Свободный объём диска             |
| `hostname`          | Имя хоста                         |
| `IP address`        | IP-адрес компьютера               |

Выбранный набор параметров позволяет получить информацию сразу о нескольких составляющих системы: операционной системе, аппаратной части, Python-среде, дисковом пространстве и сетевых параметрах. При этом программа не собирает большое количество второстепенных данных

## Используемые модули

В программе используются только стандартные модули Python:

### `platform`

Используется для получения информации об операционной системе и аппаратной платформе.

В программе с его помощью получаются:

- название ОС;
- версия ОС;
- релиз ОС;
- архитектура;
- информация о процессоре.

### `os`

Используется для взаимодействия с операционной системой средствами Python.

В программе используется для получения:

- имени пользователя;
- текущей рабочей директории;
- количества логических процессоров.

Также `os` используется для получения абсолютного пути к созданному JSON-файлу.

### `socket`

Используется для получения сетевой информации.

В программе с его помощью определяются:

- имя компьютера;
- IP-адрес;
- имя хоста.

### `sys`

Используется для получения информации о текущем интерпретаторе Python.

В программе с его помощью определяется версия Python, под которой запускается скрипт.

### `shutil`

Используется для получения информации о файловой системе.

Функция `shutil.disk_usage()` позволяет получить:

- общий объём диска;
- занятый объём;
- свободное место.

При этом не требуется запускать системные утилиты операционной системы.

### `json`

Используется для сохранения результатов работы программы в формате JSON.

С помощью `json.dump()` словарь с собранной информацией записывается непосредственно в файл.

### `datetime`

Используется для получения текущих даты и времени. Это позволяет сохранить время, в которое проводился сбор информации.

## Обоснование выбора модулей

Внешние модули в данной лабораторной работе **не использовались**.

Все необходимые для выполнения задания возможности уже предоставляются стандартной библиотекой Python. Использование стандартных модулей позволяет не устанавливать дополнительные зависимости и упрощает запуск программы на разных операционных системах.

Например, для получения информации о процессоре и ОС используется `platform`, для дискового пространства — `shutil`, для сетевой информации — `socket`.
В частности, можно было бы использовать сторонний модуль `psutil` для получения более подробной информации о системе, однако в рамках данной лабораторной работы это избыточно, поскольку выбранные параметры можно получить средствами стандартной библиотеки Python.

## Ограничения

При разработке программы не использовались стандартные утилиты операционных систем, такие как команды Windows, Linux или macOS для определения версии системы, дискового пространства или сетевых параметров.

Получение информации выполняется непосредственно средствами Python через стандартные модули.
